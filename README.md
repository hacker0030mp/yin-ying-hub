## ลิ้งค์/URL=[https://github-lock-code.netlify.app]

อธิบายแบบง่าย ๆ ทีละส่วน:

API Key – รหัสสำหรับเชื่อมต่อหรือยืนยันการใช้งานระบบ

IP Address – หมายเลขประจำการเชื่อมต่ออินเทอร์เน็ต

Security Key – กุญแจรักษาความปลอดภัย

URL Web Target – ลิงก์เว็บไซต์ที่ต้องการกำหนดเป้าหมาย

ใส่โค้ด – นำโค้ดที่ต้องการปกป้องมาใส่ เช่น Lua หรือ JavaScript

ป้องกันโค้ด – ระบบช่วยเพิ่มการป้องกันไม่ให้คนอื่นนำโค้ดไปใช้โดยง่าย

ทดสอบระบบ – ตรวจสอบว่าระบบป้องกันทำงานได้หรือไม่
